# HISTORY — PBGE Intake Retrofit Session — 2026-03-14

*When to pull: building the origin narrative, any content that shows the behind-the-scenes discipline of how Speaker Academy's marketing infrastructure was built. Shows the level of rigor applied to external systems before adoption.*

---

## What This Session Was

A working session to retrofit the Personal Brand Growth Engine (PBGE) intake documents to the current standard — a standard developed over multiple sessions through repeated pressure testing and gap analysis. The PBGE is an external marketing system by Beau / ProsperityFrameworks.com, evaluated for adoption into Speaker Academy.

The current standard requires: reading both sources in full before any analysis, a Step 1 test (state opening argument, main teaching, and closing from memory before touching the file), full gap analysis line by line, pressure test on every gap, pressure test on the pressure test, and explicit labeling of PDF-only additions, transcript-only additions, inference, and discrepancies. Plus five structural sections in every file: WHY THIS DOCUMENT EXISTS, DECISION POINTS, RELATIONSHIP TO OTHER DOCUMENTS, REREAD CHECKLIST, STATUS block.

## What Went Wrong

During DOC-05, Claude searched for the existing file at the wrong folder level. The PBGE folder has a subfolder — `01 - Intake/` — where all DOC files live. The search ran at the root level, returned nothing, and Claude concluded the file did not exist. A new file was written to the wrong location.

The original file was in the vault the entire time. Anthony caught it. Claude verified. The misplaced file was flagged for manual deletion in Obsidian.

The error was a conclusion drawn from a search that returned no results — treated as proof of absence rather than as a signal to look deeper. One additional search would have caught it before any action was taken.

## Why This Matters for the Origin Narrative

Speaker Academy was not built casually. The marketing infrastructure behind it — including the evaluation of external systems like the PBGE — was put through a documented, rigorous intake process. Every document read in full. Every gap identified and pressure tested. Every inference labeled. Every discrepancy preserved without collapsing.

That level of discipline is part of the story. The course teaches people to communicate with precision and intention. The build process reflects the same standard.
