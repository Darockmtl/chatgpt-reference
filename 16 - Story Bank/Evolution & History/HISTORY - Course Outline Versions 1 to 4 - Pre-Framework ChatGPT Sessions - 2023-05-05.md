# HISTORY — Course Outline Versions 1–4 — Pre-Framework ChatGPT Sessions — 2023

*Consolidated from four INBOX files: Early Course Outline, Version 2, Version 3, Version 4.*
*All created May 2023. All pre-date the Discover → Design → Deliver framework.*
*Pull when building: origin narrative, keynote journey content, sales page evolution story, or course development history.*

> These outlines were built by prompting ChatGPT as a public speaking coach before any proprietary framework existed. They represent the raw thinking that preceded Discover → Design → Deliver. The current course structure supersedes all of them entirely. Preserved for lineage, not for content.

---

## What these capture

The evolution of how the course was conceived across four ChatGPT sessions in May 2023:

**Version 1 (Early Draft):** A 7-module ChatGPT-generated outline covering nervousness, voice training, vocal techniques, speech structure, types of speeches, rhetoric and storytelling, and stage performance. Flagged at the time as potential bonus content. Created 2023-05-05.

**Version 2:** A 12-module expansion adding mindset, audience analysis, design thinking, and engaging techniques. Same session thread as Version 1, iterated in response to a longer brief. Introduced the idea of design thinking as a module — which later became the Design phase of the framework. Created 2023-05-05.

**Version 3:** A 12-module version that introduced empathy as the mindset module entry point, and added the concept of audience-centered communication explicitly. Also introduced facilitation techniques as an engagement module. Addressed directly to the student as "you." Created 2023-05-05.

**Version 4:** The most developed pre-framework version. A structured 12-module outline with explicit goals, explanations, examples, summaries, and multiple-choice quizzes for each module. Added 30-minute video format per module and a commentary section for questions. Closest to a real course spec — but still entirely AI-generated with no proprietary framework underneath. Created 2023-05-06.

---

## Key pattern across all four versions

Every version defaulted to nervousness as Module 1. Every version treated confidence as a direct output. Every version separated voice, body, and structure into discrete modules without a unifying framework.

The Discover → Design → Deliver framework solved exactly what these outlines could not: a through-line that made the modules a system instead of a list.
