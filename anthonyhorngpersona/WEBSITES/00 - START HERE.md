## WHAT NOT TO DO — Failure modes from the 2026-05-12 session

These are real patterns to avoid. Calling them out explicitly so the next Claude doesn't repeat them.

1. **Do not build before strategy is locked.** The 2026-05-12 session burned hours when Claude jumped to producing HTML rebuilds before reading the vault. The vault has extensive prior work — REBUILD BRIEF, DESIGN STUDY, positioning seeds, ICP. Read it first. Always.

2. **Do not skip the geographic qualifier in SERP analysis.** Searches without "Québec" or "Montréal" return France-dominated or US-dominated SERPs. The ICP searches with qualifiers. Use them.

3. **Do not equate "animateur" universe with "maître de cérémonie" universe.** Different SERPs, different competitors, different intent. Both must be addressed separately.

4. **Do not assume bilingual side-by-side site structure is good for SEO.** Randy Johnston's site proves it isn't. The Master Plan's two-site architecture (animateur.ca FR-only + anthonyhorng.com EN) is structurally correct. Confirmed by data.

5. **Do not propose copy or visual design without first having structure locked.** Structure → copy → visual. Not the other way.

6. **Do not skip the AI Overview pillar.** As of May 2026, Google AI Overview is the new top-of-page for many queries. Classical organic ranking is necessary but no longer sufficient. The spec must cover both pillars.

7. **Do not override Master Plan deferrals silently.** Full rebuild is post-Sep 19. Blockers 1 and 2 gate it. Pre-reel sprint work is in scope NOW per Master Plan. Stay within the deferral.

8. **Do not write long files.** Anthony has explicitly flagged that Claude reads long files poorly and fills gaps with invention. Files in this folder stay focused. Long-form thinking lives in SESSION CAPTURE; orientation files stay short.

9. **Do not invent capabilities or facts.** Search before answering. Especially for: tool availability, plugin behaviors, SEO mechanics, AI Overview behavior. Never fabricate plausible-sounding answers.

10. **Do not skip vault file reads at session start.** This folder + governing files (above) load at the start of any session that touches website strategy.
