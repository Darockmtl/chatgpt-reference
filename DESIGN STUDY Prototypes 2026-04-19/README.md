# Design Study Prototypes — 2026-04-19

Three working HTML prototypes from the design-study session documented in:

`../DESIGN STUDY - anthonyhorng.com and holdtheroom.com Site Architecture Exploration - 2026-04-19.md`

## Files

**anthonyhorng-practitioner-home-v3.html** (recommended)
Prototype 3 of the session. Practitioner's personal site for anthonyhorng.com. Not an umbrella, not a keynote site, not a conversion site. Eight sections: header, hero, worldview, methodology, origin, proof, routes, orbit (email). Recommended structure for the post-MUDGIRL rebuild.

**holdtheroom-en-mc-site-v1.html** (recommended)
Prototype 4 of the session. EN MC conversion site for holdtheroom.com. Reel as hero, four Master-Plan-confirmed service buckets (corporate / galas / bilingual / conferences), three-phase process section, producer-kit path for agencies, real qualifying inquiry form. Recommended structure for holdtheroom.com when post-MUDGIRL rebuild begins.

**anthonyhorng-umbrella-language-first-router-v2.html** (not recommended — kept for reference)
Prototype 2 of the session. Umbrella site for anthonyhorng.com with a language-first router (EN / FR tiles) as the primary CTA. Saved for reference after the design-study session concluded this structure was wrong for Anthony's situation: language-first routing costs the bilingual ICP a click, hot referrals hit a four-step path to inquiry, and the umbrella has no conversion event of its own. Useful as the proof-by-contradiction that made Prototype 3 necessary. Includes thinking notes inline.

## How to view

Double-click any file to open in a browser. All three are self-contained with inline CSS — no external dependencies, no build step, no fonts to download (falls back to system fonts and Georgia for the serif display type).

## Status

Thinking tools, not launch copy. Preserved here so the visual decisions from the session are reviewable without a chat session. When the governing-layer session happens and the real rebuild begins, the recommended prototypes become reference material, not final design.
