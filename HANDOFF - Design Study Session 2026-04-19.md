## WHAT THE SESSION DID

### Starting point

Anthony asked: "Can you copy the format or be inspired by a website to make my website?" He provided cassandraworthy.com as the reference. He named anthonyhorng.com as the target, then clarified the work would later move to WordPress (not the current Kajabi). He stated explicitly: this is a thinking tool, not launch copy.

### The four prototypes built

The session produced four prototypes, each in response to a reframing of what anthonyhorng.com is for. The reframings happened in sequence because each prototype surfaced a structural problem that forced a rethink.

**Prototype 1 — Cassandra structure cloned literally.** Failed. The three-product row (MC / Speaker Academy / Workshops+Keynote) physically demonstrated the Governing Layer Gap — three buyers do not belong on one page. Not preserved as an HTML file (structural description in the design-study markdown).

**Prototype 2 — Umbrella with language-first router.** Failed. Language-first routing costs the bilingual ICP a click they didn't need to make, hot referrals hit a four-step inquiry path, and the umbrella has no conversion event of its own. Preserved as an HTML file in the prototypes folder, labeled "not recommended — kept for reference."

**Prototype 3 — Practitioner's personal site for anthonyhorng.com.** Recommended. Eight sections: header / hero / worldview / methodology / origin / proof / routes / orbit (email). The person is the frame. The argument earns attention. Routes appear at the bottom. The conversion event is an email signup, not a transaction. Reference analogs shifted from Cassandra Worthy to Vinh Giang / Shadé Zahrai / Marie Forleo (pre-book). Preserved as an HTML file.

**Prototype 4 — holdtheroom.com as EN MC conversion site.** Recommended. Reel as hero, four Master-Plan-confirmed service buckets (corporate / galas / bilingual / conferences), three-phase process section, producer-kit path for agencies, real qualifying inquiry form. Cassandra's structural pattern that didn't fit anthonyhorng.com does fit this site. Preserved as an HTML file.

### The reframings, in order

1. **"Copy cassandraworthy.com"** → produced Prototype 1 → failed on three-buyer routing
2. **"It's an umbrella that routes to the destination sites"** → produced Prototype 2 → failed on routing-as-purpose being too thin
3. **"Pretend everything is developed and approved"** → produced the Phase 3 keynote-site reasoning → failed because the optimal state requires conditions that do not exist
4. **"Not keynote, no agency yet"** → produced Prototype 3 (practitioner's personal site) → worked because it accepted the constraint and stopped trying to convert all three buyers from one page
5. **"What would holdtheroom.com look like?"** → produced Prototype 4 → worked because the Cassandra pattern fits a single-buyer conversion site

The meta-pattern: each reframing was a correction to the previous prototype's structural failure. The final answer required dropping the original reference site's structural logic entirely and starting from Anthony's actual conditions.

## DURABLE DISCOVERIES

Two insights crystallized from the session and were saved as standalone files:

### 1. The Governing Layer Gap is now a physical design problem

[[INSIGHT - Governing Layer Gap as a Physical Design Problem - 2026-04-19]]

The March 19 2026 insight named the gap as a content-routing problem. The April 19 session showed it is also a structural design problem: when you try to serve three buyers from one site, the page's architecture physically bends in a way that is visible in a prototype. You can see the three-product row trying and failing to host three buyers. The gap isn't fixable at the page level — only at the architecture level.

### 2. anthonyhorng.com is a practitioner's personal site

[[INSIGHT - anthonyhorng.com Is a Practitioner's Personal Site - 2026-04-19]]

After four failed reframings, the site's actual category became visible. It is not an umbrella, not a keynote speaker site, not a conversion site. It is a practitioner's home — a site for a person who runs multiple offerings, where the person is the frame and the offerings are expressions of the frame. Reference analogs: Vinh Giang, Shadé Zahrai, Marie Forleo pre-book. The conversion event is relationship (email list), not transaction.
